# Torneo Absurdo

**EN** · Absurd fights between (sort of 👀) legendary characters, simulated live with no script: nobody knows who wins until it happens. Watch together, bet your (fake) coins, enjoy the chaos.

- 100% original "homage" characters, simulated by our own deterministic engine.
- **Provably fair**: each fight's seed is committed (SHA-256) before betting opens and revealed after, so anyone can re-simulate it.
- No real money. Ever.
- Stack: Rust (engine + axum server), SvelteKit, PixiJS, Postgres.
- Docs are in Spanish; code, commits and identifiers are in English.
